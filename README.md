# כסף (Kesef) — מנהל סיסמאות מקומי לטלפון

אפליקציית **טלפון מקומית** (לא אפליקציית דפדפן) לשמירת סיסמאות, מותאמת במיוחד
לאנשים מבוגרים. בנויה ב‑React Native / Expo, רצה על אייפון ואנדרואיד,
**ללא שום חיבור לאינטרנט** — האפליקציה לא שולחת ולא מקבלת מידע משום שרת,
וכל הנתונים נשמרים אך ורק על המכשיר.

## עקרונות

- **פשטות ומעט לחיצות** — כל מסך מציג מעט מאוד אפשרויות, בכפתורים גדולים.
- **טקסט גדול ובניגודיות גבוהה** — פונט Rubik, טקסט שחור על רקע לבן.
- **דו-לשוני** — עברית (מיושר לימין) ואנגלית (מיושר לשמאל), עם כפתור החלפת שפה.
- **ללא סיסמת-על** — הכניסה תתבצע בעזרת שאלות זיכרון אישיות או זיהוי ביומטרי (בשלב הבא).
- **מקומי ובלי אינטרנט** — אין קריאות רשת; הכול נשמר על הטלפון בלבד.

## מה כבר קיים (שלב ראשון)

### שאלון הרשמה ראשוני — 3 שלבים
1. **קצת עליך** — שם, מין (בן/בת), מצב משפחתי, שם בן/בת הזוג (מותאם למין ולמצב המשפחתי),
   ושמות הילדים (עם אפשרות להוסיף שדות).
2. **דרכי יצירת קשר** — אימייל, כתובת ומיקוד, מספר טלפון.
3. **שאלות זיכרון אישיות** — מאגר שאלות שחלקן מותאמות לתשובות הקודמות
   (שם בן/בת הזוג, שם הילד וכו'), עם אפשרות להוסיף שאלות משלך.

### העמוד הראשי
לאחר סיום ההרשמה מתבצעת כניסה לעמוד הראשי, ובמרכזו כפתור **+** גדול
להוספת סיסמאות חדשות. סיסמאות שמורות מוצגות בכרטיסים גדולים עם הצגה/הסתרה ומחיקה.

## הרצה על הטלפון

```bash
npm install
npx expo start
```

לאחר מכן סורקים את ה‑QR עם אפליקציית **Expo Go** (אנדרואיד/אייפון) כדי לראות
את האפליקציה רצה על המכשיר. ליצירת קובץ התקנה עצמאי (APK לאנדרואיד / IPA לאייפון)
משתמשים ב‑EAS Build:

```bash
npx eas build -p android   # או: -p ios
```

> בבנייה לפרודקשן מומלץ להסיר את הרשאת הרשת (INTERNET) כדי שהאפליקציה תהיה
> מקומית לחלוטין גם ברמת מערכת ההפעלה.

## מבנה הקוד

- `App.tsx` — נקודת הכניסה: טעינת פונטים, טעינת הפרופיל מהאחסון המקומי, וניתוב בין הרשמה לעמוד הראשי.
- `components/Onboarding.tsx` — שאלון ההרשמה בן 3 השלבים.
- `components/MainScreen.tsx` — העמוד הראשי, כפתור ההוספה וכרטיסי הסיסמאות.
- `components/ui.tsx` — רכיבי UI גדולים ונגישים משותפים.
- `lib/i18n.ts` — מחרוזות בעברית ובאנגלית והתאמות לשון (מגדר/מצב משפחתי) ומאגר השאלות.
- `lib/storage.ts` — שמירה/טעינה מקומית (AsyncStorage).
- `lib/lang.tsx` — ניהול שפה וכיווניות (RTL/LTR).
- `lib/theme.ts` — צבעים ופונטים.
- `lib/types.ts` — טיפוסי הנתונים.

## הצעדים הבאים

- מסך כניסה חוזר — אימות בעזרת שאלות הזיכרון או זיהוי ביומטרי (Face ID / טביעת אצבע, `expo-local-authentication`).
- הצפנת הנתונים מאחורי ה‑Keychain/Keystore של המכשיר (`expo-secure-store`).
- עריכת סיסמאות קיימות וחיפוש.
